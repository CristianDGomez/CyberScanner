# 🔐 CyberScanner – Escáner básico de puertos

CyberScanner es un proyecto educativo de ciberseguridad desarrollado en Python.  
Permite escanear puertos de una IP o dominio, identificar cuáles están abiertos y generar un reporte automático con los resultados.

Este proyecto está pensado para prácticas de:

- Reconocimiento básico (recon)
- Principios de análisis de red
- Escaneo de puertos
- Automatización en Python
- Documentación técnica

---

## 🛠️ Tecnologías utilizadas

- Python 3
- Sockets
- Manejo de archivos (reportes)
- CLI (interfaz en consola)
